# XangMod

A competitive gameplay modification for *Chivalry: Medieval Warfare*. Ships as
**SlumpMod**. Dedicated to the greatness of Emperor Bill.

Balance changes, netcode fixes, an RCON admin protocol, first-person spectating and a
custom character and weapon customization system.
